## Exploratory Data Analysis

The EDA process included:

Data loading and exploration
- Data cleaning and validation
- Checking for missing and duplicate values
- Data type inspection
- Analysis of purchase frequency and spending distribution
- Visualization of customer buying patterns

## Dataset

The dataset contains customer sales behaviour data including:
- Customer demographics
- Purchase frequency
- Product categories
- Spending amounts
- Transaction details
- promo codes
